# Data Dictionary

| Column       | Description                     |
| ------------ | ------------------------------- |
| Order Date   | Date the transaction was placed |
| Product Name | Name of the candy product       |
| Division     | Product division                |
| Region       | Geographic sales region         |
| Units        | Number of units sold            |
| Sales        | Revenue generated               |
| Cost         | Product cost                    |
| Gross Profit | Sales minus Cost                |
| Gross Margin | Gross Profit divided by Sales   |
| Factory      | Manufacturing facility          |
